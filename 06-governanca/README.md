# 06 - Governança em IA & Business Analytics

## Objetivo
Disciplina integradora: documenta a arquitetura dos 9 módulos, ética, LGPD, riscos, KPIs e o que foi ou não integrado.

## Arquivos
- [relatorio-abnt.md](relatorio-abnt.md): relatório no formato ABNT/FIAP (converter para DOCX/PDF na entrega; instruções de formatação no topo do arquivo).
- [roteiro-video.md](roteiro-video.md): roteiro cronometrado do vídeo de 5 a 7 min.
- [kpis.py](kpis.py): calcula os KPIs a partir de `dados/ocorrencias.csv`.

## Como rodar
```bash
pip install pandas
python 06-governanca/kpis.py
```

## Pendências
Procure por `[PENDENTE` no relatório: são trechos que dependem dos resultados dos outros módulos.
A **Conclusão** deve ser escrita pelo aluno (o enunciado proíbe gerá-la com IA).
Preencher nome, RM e professor na capa e o link do vídeo no tópico Links.

## Integração
Lê o contrato de dados comum (entidade Ocorrência) produzido por Visão (09), IoT (07), GenAI (05) e RPA (01), e consolida a matriz de integração (Quadro 6).
